# Malicious URL Classifier: คู่มือการใช้งาน

โปรแกรมตรวจ URL ว่าเป็น **benign** (ปลอดภัย), **phishing** (เว็บหลอกขโมยข้อมูล), **malware** (ลิงก์แจกไฟล์อันตราย)
หรือ **defacement** (เว็บที่ถูกเจาะแก้ไข) โดยดูจากข้อความ URL อย่างเดียว โปรแกรมไม่เปิดเว็บปลายทาง จึงปลอดภัยต่อผู้ใช้

## 2. หน้าจอหลัก

ด้านบนมี 4 แท็บ ได้แก่ **ตรวจ URL**, **ตรวจหลาย URL**, **เกมทาย URL** และ **เกี่ยวกับโมเดล**

---

## 3. แท็บ "ตรวจ URL" (ตรวจทีละลิงก์)

1. พิมพ์หรือวาง URL ในช่อง **กรอก URL ที่ต้องการตรวจ** หรือกดปุ่มตัวอย่าง **เว็บปกติ / Phishing / Malware / Defacement**
2. กดปุ่ม **Predict**
3. อ่านผล:

| ส่วนที่แสดง | ความหมาย |
|---|---|
| **กล่องผลลัพธ์** | ประเภทที่โปรแกรมทาย และความน่าจะเป็น สีเขียว = ปลอดภัย, สีแดง / ส้ม = อันตราย |
| **ความหมาย / คำแนะนำ** | อธิบายว่าประเภทนี้คืออะไร และควรทำอย่างไรต่อ |
| **กฎการตัดสิน** | บอกเหตุผล เช่น "P(benign) = 0.9% ต่ำกว่าเกณฑ์ 60% จึงเลือกคลาสอันตรายที่น่าจะเป็นที่สุด" |
| **ความน่าจะเป็นของแต่ละคลาส** | แถบสีของทั้ง 4 ประเภท เส้นดำบนแถบ benign คือเกณฑ์ 60% ถ้า benign ไม่ถึงเส้นนี้ โปรแกรมจะเตือน |
| **ส่วนประกอบของ URL** | แยก scheme, โฮสต์, path, query และบอกว่าใช้ IP, ลิงก์ย่อ หรือมีคำล่อลวงหรือไม่ |
| **จุดสังเกตจากโครงสร้าง URL** | ป้ายสีแดงบอกจุดน่าสงสัย เช่น "ใช้ IP แทนชื่อโดเมน", "มีคำล่อลวง 3 คำ" |
| **ประวัติการตรวจ** | กดเปิดเพื่อดู URL ที่ตรวจไปแล้วในรอบนี้ |

- ถ้าความน่าจะเป็นต่ำกว่า 60% จะมีข้อความเตือนว่าผลไม่ชัดเจน ควรตรวจซ้ำด้วยวิธีอื่น
- วาง URL แบบ defang ได้ เช่น `hxxp://evil[.]com` โปรแกรมจะแปลงกลับเป็น URL ปกติให้เอง

---

## 4. แท็บ "ตรวจหลาย URL" (ตรวจทีละหลายลิงก์)

1. วาง URL ในกล่อง **บรรทัดละ 1 รายการ** หรือกด **อัปโหลด CSV** ที่มีคอลัมน์ชื่อ `url` (ทำได้ทั้งสองแบบพร้อมกัน)
2. กดปุ่ม **ตรวจทั้งหมด** (สูงสุด 5,000 รายการต่อครั้ง)
3. จะได้:
   - **ตัวเลขสรุป** จำนวน URL แต่ละประเภท
   - **กราฟแท่ง** สรุปผล
   - **ตาราง** URL, ประเภทที่ทาย และความน่าจะเป็น
   - ปุ่ม **ดาวน์โหลดผลเป็น CSV** สำหรับเก็บผล

---

## 5. แท็บ "เกมทาย URL"

1. โปรแกรมสุ่ม URL มา 10 ข้อ
2. ดู URL ในกล่อง แล้วกดปุ่มประเภทที่คิดว่าใช่: **benign / phishing / malware / defacement**
3. ระบบเฉลยคำตอบ และบอกว่าคุณกับ AI ตอบถูกหรือผิด
4. กด **ข้อต่อไป** จนครบ 10 ข้อ แล้วดูว่าใครได้คะแนนมากกว่า
5. กด **เริ่มเกมใหม่ (สุ่มชุดใหม่)** เพื่อเล่นอีกรอบ

- แถบด้านบนแสดงความคืบหน้า: เขียว = ตอบถูก, แดง = ตอบผิด
- เอาเมาส์ชี้ที่ปุ่มคำตอบเพื่อดูความหมายภาษาไทย

---

## 6. แท็บ "เกี่ยวกับโมเดล"

แสดงข้อมูลโมเดลที่ใช้ ผลการวัดความแม่นยำ และข้อจำกัดของโปรแกรม

---

## 7. ข้อควรรู้

- URL อันตรายในตารางและในเกมแสดงแบบ **defang** (`http` → `hxxp`, `.` → `[.]`) เพื่อไม่ให้เผลอกดเปิด **อย่าแปลงกลับแล้วเปิดดู**
- โปรแกรมดูจากข้อความ URL อย่างเดียว เว็บปลอมที่ฝากบนบริการใหญ่ (เช่น Google Docs) อาจหลุด และเว็บปกติบางเว็บอาจถูกเตือนผิด
- ผลเป็นการประเมินโดยโมเดล ใช้ประกอบการตัดสินใจ ไม่ใช่คำตัดสินสุดท้าย
